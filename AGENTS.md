# Mira shared work

This repository is public: never add secrets.

- Start new work with the [new-task-branch](skills/new-task-branch/SKILL.md) skill.
- Prepare pull requests with the [pr-generation](skills/pr-generation/SKILL.md) skill, including its body format.
- Track work in the [Mira Project](https://github.com/users/Papidev/projects/2); cross-repository issues live in `Papidev/mira-explorer`.
- Authenticate GitHub operations as `Papidev`; verify the identity before creating or changing PRs.
- Changing a schema in `src/` changes the content API contract: update Explorer before or together with the Admin.
